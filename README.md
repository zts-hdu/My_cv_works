# 周天生 | 作品集

静态作品集，使用相对路径加载 `assets/` 中的图片和视频，可直接部署到 GitHub Pages。

## 发布到 GitHub Pages

1. 在 GitHub 创建公开仓库 `My_cv_works`，上传 `index.html`、`style.css`、`assets/` 和本文件（无需上传 `references/`）。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择 `main` 分支和 `/ (root)`，保存。
3. 部署完成后访问 `https://zts-hdu.github.io/My_cv_works/`（实际地址以 Pages 设置显示为准）。

也可以将仓库命名为 `zts-hdu.github.io`，部署后使用 `https://zts-hdu.github.io/`。本地预览可在本目录运行 `python3 -m http.server 8000`。
